# Техническое задание: Instagram Clone (версия «осень 2026»)

## 1. Цель

Создать функциональный клон Instagram, максимально близкий к актуальному приложению (октябрь 2026) по функциям, внешнему виду и поведению. Проект учебно-портфолийный: реальная архитектура продакшн-уровня, но без рекламы, монетизации и ML-рекомендаций масштаба Meta.

**Платформы:**
- Web (десктоп + мобильная ширина): приоритет №1
- REST + WebSocket API: приоритет №1
- Мобильное приложение (iOS/Android, Expo): после стабилизации API (этап M12)

## 2. Роли пользователей

| Роль | Возможности |
|---|---|
| Гость | Страницы входа и регистрации; публичные профили и посты по прямой ссылке (только просмотр) |
| Пользователь | Всё, что описано в разделе 4 |
| Приватный аккаунт | Как пользователь, но контент видят только одобренные подписчики |
| Администратор | Модерация жалоб, блокировка аккаунтов (минимальная админка, этап M11) |

## 3. Объём (scope)

### Входит
Аккаунты, профили, подписки, посты (фото, видео, карусели), лента, лайки, комментарии, сохранения и коллекции, репосты, хэштеги, упоминания, отметки людей, геометки, Stories (включая Close Friends и Highlights), Reels, Explore, поиск, Direct (личные и групповые чаты, медиа, голосовые, Notes), уведомления (в реальном времени + web push), настройки приватности, «Ваш алгоритм», тёмная тема, ru/en.

### Не входит (возможно в будущем)
Прямые эфиры (Live), магазин и реклама, платные подписки и Instagram Plus, редактор Edits с AI, Threads, звонки, полноценная ML-рекомендательная система (используем эвристическое ранжирование).

## 5. Экраны (web)

| Маршрут | Экран |
|---|---|
| `/login`, `/register`, `/verify-email`, `/reset-password` | Аутентификация |
| `/` | Главная: сторис + лента + рекомендации справа |
| `/explore` | Explore |
| `/explore/tags/[tag]` | Хэштег |
| `/explore/locations/[id]` | Место |
| `/reels`, `/reels/[id]` | Reels |
| `/direct/inbox`, `/direct/t/[id]`, `/direct/requests` | Direct |
| `/stories/[username]/[id]` | Просмотр сторис (полноэкранно) |
| `/p/[id]` | Пост: отдельная страница, при переходе из ленты или сетки открывается модалкой |
| `/[username]` (+ `/reels`, `/reposts`, `/tagged`, `/saved`) | Профиль |
| `/accounts/edit`, `/accounts/settings/*` | Настройки |
| `/notifications` | Уведомления (мобильная ширина; на десктопе боковая панель) |
| `/map` | Карта (P2) |

**Навигация:**
- десктоп ≥1264px: левый сайдбар с подписями;
- 768–1263px: узкий сайдбар из иконок;
- <768px: верхняя панель (логотип, уведомления) и нижняя панель **Главная · Reels · Direct · Поиск · Профиль** (порядок Instagram 2025–2026).

## 6. Нефункциональные требования

| Область | Требование |
|---|---|
| Производительность | LCP < 2.5 с на главной; лента без подтормаживаний (виртуализация длинных списков); изображения в нескольких размерах (WebP/AVIF) с blurhash-заглушками |
| API | p95 < 200 мс для чтения ленты (с кэшем); курсорная пагинация везде, без offset |
| Безопасность | Хэши argon2id; refresh-токен в httpOnly + Secure + SameSite cookie; rate limiting (вход, регистрация, комментарии, сообщения); валидация всех входных данных (Zod); защита от IDOR (проверка прав на каждый ресурс); CSP и helmet |
| Приватность | Приватные аккаунты и блокировки соблюдаются во **всех** выдачах: лента, поиск, Explore, комментарии, лайки, Direct |
| Доступность | Управление с клавиатуры, aria-атрибуты, alt-тексты, контраст WCAG AA |
| Адаптивность | 360px – 2560px |
| Локализация | ru (по умолчанию), en |
| Надёжность | Медиа обрабатываются фоновыми задачами с повторами; сообщения Direct не теряются при переподключении |
| Наблюдаемость | Структурированные логи, Sentry для ошибок, health-check |
| Качество | Строгий TypeScript; e2e-тесты API; e2e-тесты ключевых сценариев в браузере (Playwright) |

## 7. Ограничения медиа

| Тип | Лимит |
|---|---|
| Фото в посте | до 20 штук, до 20 МБ каждое, JPEG/PNG/WebP/HEIC → храним WebP 1080/640/320 px |
| Видео в посте | до 60 с; Reels до 3 мин; сторис до 60 с; до 500 МБ; на выходе MP4 H.264 + постер (HLS позже) |
| Аватар | до 10 МБ, храним 320 и 150 px |
| Голосовое в Direct | до 60 с |
