# Roadmap и прогресс

Работа идёт **вертикальными этапами**: в каждом этапе сначала делается бэкенд фичи, затем её фронтенд. После этапа фича полностью работает от базы данных до экрана. Команда `делай M3` выполняет весь этап по порядку.

Обозначения: `[x]` готово · `[~]` в процессе · `[ ]` не начато.
