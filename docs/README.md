# Документация проекта Instagram Clone

Полный клон Instagram (актуальная версия на осень 2026): веб-приложение, бэкенд и (позже) мобильное приложение в одном монорепозитории.

## Как давать задачи

Каждая задача имеет ID. Достаточно написать команду:

| Команда | Что произойдёт |
|---|---|
| `делай BE-3` | одна задача бэкенда |
| `делай FE-4` | одна задача фронтенда |
| `делай M2` | весь этап целиком: сначала бэкенд, потом фронтенд этого этапа |
| `статус` | сводка: что сделано, что дальше (по [07-roadmap.md](07-roadmap.md)) |

Рекомендуемый путь: идти по этапам `M0 → M1 → M2 → …` из [07-roadmap.md](07-roadmap.md). Каждый этап — законченный вертикальный срез: после него фича полностью работает от базы данных до экрана.

## Правило «готово» (Definition of Done)

Задача считается выполненной, когда:

1. Код написан по архитектуре из [02-architecture.md](02-architecture.md) (FSD на фронте, модули на беке).
2. API соответствует [04-api.md](04-api.md). Если контракт пришлось изменить, документ обновлён в той же задаче.
3. Проходят `pnpm typecheck`, `pnpm lint` (включая Steiger для FSD) и `pnpm build`.
4. Для бэкенда есть e2e-тесты на основные сценарии задачи.
5. Фича проверена вручную в браузере (светлая и тёмная тема, мобильная ширина).
6. Изменения закоммичены отдельным коммитом с ID задачи, например `feat(api): BE-3 auth module`.
7. В [07-roadmap.md](07-roadmap.md) задача отмечена `[x]`.
